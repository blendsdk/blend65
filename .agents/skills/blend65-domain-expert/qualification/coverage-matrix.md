## Depth Facets

Each coverage row must eventually contain all eight facets. A filled circle means the knowledge
owner and its evidence exist; an empty circle is incomplete. `N/A(reason)` is allowed only after
review.

| Mark | Facet |
|---|---|
| F | Authoritative facts and variants |
| I | Interactions with other compiler/machine concerns |
| C | Blend65/compiler/generated-code consequences |
| E | Expert idioms and zero-cost abstractions |
| X | Failure modes, traps, and counterexamples |
| D | Actionable design/review/diagnostic rules |
| S | Source traceability |
| Q | Discriminating qualification case |

when authored, eight facets, source keys, case IDs, status, and review evidence. Phase 1
intentionally leaves replacement headings and facets incomplete instead of pretending future
