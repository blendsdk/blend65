# Charset Design: Armenian Glyphs

> **Document**: 03-charset-design.md
> **Parent**: [Index](00-index.md)

## Overview

This document defines the 8×8 pixel bitmap for each of the 38 Armenian uppercase letters plus the space character. Each glyph is shown as a pixel grid and its corresponding 8-byte hex values.

**Grid convention:**
- `.` = pixel off (0)
- `X` = pixel on (1)
- Each row is 8 pixels = 1 byte
- 8 rows per character = 8 bytes per character

## Character Set Memory Layout

The full charset is 2048 bytes (256 characters × 8 bytes each):

| Char Codes | Content |
|------------|---------|
| 0–37 | Armenian uppercase letters (Ա–Ֆ) |
| 38 | Space (blank) |
| 39–47 | Digits 0–9 (optional) |
| 48–255 | Blank (all zeros) |

## Charset Padding

Characters 39–255 are all blank (filled with `$00`). The total `@charset` array is 2048 bytes:
- Characters 0–38: 39 × 8 = 312 bytes of glyph data
- Characters 39–255: 217 × 8 = 1736 bytes of zeros
- **Total: 2048 bytes**
