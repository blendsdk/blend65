# VICE Emulator Integration

> **Document**: 05-vice-integration.md
> **Parent**: [Index](00-index.md)

## Overview

Create `scripts/diag_vice.sh` — a new script that runs compiled PRG files in the VICE C64 emulator, dumps memory/registers, takes screenshots, and compares runtime state against expected values.

This is the **most impactful** improvement: it verifies actual runtime behavior, catching bugs that static analysis cannot.

## Architecture

### Script: `scripts/diag_vice.sh`

```
Usage: ./scripts/diag_vice.sh <prg-file> <expected.json> [output-dir] [cycles]

Arguments:
  <prg-file>        Path to the .prg file to run
  <expected.json>   Path to expected values JSON file
  [output-dir]      Output directory (default: alongside prg-file)
  [cycles]          Cycle limit (default: 5000000 = ~5 seconds at 1MHz)
```

### Execution Flow

```
1. Validate inputs (PRG exists, JSON valid)
2. Generate VICE monitor script (.mon file)
3. Launch VICE with warp + limitcycles + moncommands + exitscreenshot
4. Wait for VICE to complete (cycle limit or quit)
5. Parse memory dumps
6. Compare against expected values
7. Generate pass/fail report
```

### 2. Monitor Script Generation

Generate a `.mon` file dynamically based on what needs to be checked:

```bash
generate_mon_script() {
  local output_dir="$1"
  local mon_file="$output_dir/verify.mon"

  cat > "$mon_file" << 'EOF'
; Blend65 Diagnostic — VICE Monitor Commands
; Generated by diag_vice.sh

; Dump zero page ($00-$FF) — compiler temp variables
save "zeropage.bin" 0 0000 00ff

; Dump screen memory ($0400-$07E7)
save "screen.bin" 0 0400 07e7

; Dump color RAM ($D800-$DBE7)
save "color.bin" 0 d800 dbe7

; Dump VIC-II registers ($D000-$D030)
save "vic.bin" 0 d000 d030

; Dump SID registers ($D400-$D41C)
save "sid.bin" 0 d400 d41c

; Dump sprite pointers ($07F8-$07FF)
save "sprite_ptrs.bin" 0 07f8 07ff

; Dump CIA registers ($DC00-$DC0F, $DD00-$DD0F)
save "cia1.bin" 0 dc00 dc0f
save "cia2.bin" 0 dd00 dd0f

; Dump program area ($0800-$CFFF)
save "program.bin" 0 0800 cfff

; Show registers
r

; Quit emulator
quit
EOF

  echo "$mon_file"
}
```

### 3. VICE Execution

```bash
run_vice() {
  local prg_file="$1"
  local mon_file="$2"
  local output_dir="$3"
  local cycles="${4:-5000000}"
  local screenshot="$output_dir/screenshot.png"

  # Change to output dir so monitor save commands write there
  cd "$output_dir"

  # Run VICE
  $VICE_BIN \
    -autostart "$prg_file" \
    -warp \
    -autostart-warp \
    -limitcycles "$cycles" \
    -moncommands "$mon_file" \
    -exitscreenshot "$screenshot" \
    +confirmonexit \
    -silent \
    > "$output_dir/vice.log" 2>&1

  local exit_code=$?

  # Return to original directory
  cd -

  return $exit_code
}
```

### 5. Memory Comparison Logic

```bash
verify_memory_checks() {
  local expected_json="$1"
  local output_dir="$2"
  local pass=0
  local fail=0
  local total=0

  # Parse memory_checks array from JSON
  local check_count=$(jq '.memory_checks | length' "$expected_json")

  for ((i=0; i<check_count; i++)); do
    local source=$(jq -r ".memory_checks[$i].source" "$expected_json")
    local offset=$(jq -r ".memory_checks[$i].offset" "$expected_json")
    local expected=$(jq -r ".memory_checks[$i].expected" "$expected_json")
    local desc=$(jq -r ".memory_checks[$i].description" "$expected_json")
    local addr=$(jq -r ".memory_checks[$i].address" "$expected_json")

    # Read actual byte from dump file
    local dump_file="$output_dir/$source"
    if [[ -f "$dump_file" ]]; then
      local actual=$(xxd -p -l 1 -s "$offset" "$dump_file")

      if [[ "$actual" == "$expected" ]]; then
        ok "\$$addr = \$$actual ✓ ($desc)"
        ((pass++))
      else
        fail "\$$addr = \$$actual, expected \$$expected ✗ ($desc)"
        ((fail++))
      fi
    else
      fail "Dump file not found: $source ($desc)"
      ((fail++))
    fi
    ((total++))
  done

  echo ""
  echo "  Results: $pass/$total passed, $fail failed"
  return $fail
}
```

### 6. Register Verification

Parse VICE monitor `r` output to check registers:

```bash
verify_registers() {
  local vice_log="$1"
  local expected_json="$2"

  # Extract register line from VICE output
  # Format: "  ADDR AC XR YR SP 00 01 NV-BDIZC"
  local reg_line=$(grep -A1 "ADDR" "$vice_log" | tail -1)

  if [[ -n "$reg_line" ]]; then
    local pc=$(echo "$reg_line" | awk '{print $1}')
    local sp=$(echo "$reg_line" | awk '{print $5}')

    echo "  PC=$pc  SP=$sp"

    # Stack pointer check
    local sp_min=$(jq -r '.stack_check.sp_min // "F0"' "$expected_json")
    local sp_dec=$((16#$sp))
    local sp_min_dec=$((16#$sp_min))

    if (( sp_dec >= sp_min_dec )); then
      ok "Stack pointer SP=\$$sp (≥ \$$sp_min) — no stack leak"
    else
      fail "Stack pointer SP=\$$sp (< \$$sp_min) — possible stack leak!"
    fi
  fi
}
```

### 7. Headless Operation Considerations

VICE on macOS may need a display. Mitigation strategies:

1. **Try headless first** — run and check if screenshots are generated
2. **If screenshot fails** — still collect memory dumps (they use monitor, not display)
3. **Fall back to `-console` mode** if available
4. **Document that screenshots may not work** in headless environments

```bash
# Test if VICE screenshot works
test_vice_screenshot() {
  local test_screenshot="/tmp/vice_test_screenshot.png"
  # Run a minimal program for 100000 cycles
  timeout 30 $VICE_BIN \
    -warp -limitcycles 100000 \
    -exitscreenshot "$test_screenshot" \
    +confirmonexit -silent 2>/dev/null

  if [[ -f "$test_screenshot" && $(filesize "$test_screenshot") -gt 0 ]]; then
    echo "Screenshots: ✅ Working"
    rm -f "$test_screenshot"
    return 0
  else
    echo "Screenshots: ❌ Not available (memory dumps still work)"
    rm -f "$test_screenshot"
    return 1
  fi
}
```

## Error Handling

| Error Case | Handling Strategy |
|------------|-------------------|
| VICE binary not found | Warn and skip VICE tests (graceful degradation) |
| VICE crashes or hangs | `timeout` wrapper with 60s limit; kill and report |
| Screenshot generation fails | Warn but continue — memory dumps are more important |
| Monitor script fails | Check vice.log for errors; report specific failure |
| Memory dump files not created | Warn — VICE may have exited before monitor commands ran |
| Cycle limit reached before program completes | Check completion sentinel; report if not set |
| JSON parsing fails | Validate JSON with `jq` before execution; report syntax errors |

## Testing Requirements

- Verify VICE launches and exits cleanly with `-limitcycles`
- Verify monitor commands produce dump files
- Verify screenshot generation (or graceful fallback)
- Verify memory comparison against known-good values
- Verify register parsing from VICE output
- Test with border-cycle program (known working)
- Test timeout behavior with infinite loop programs
