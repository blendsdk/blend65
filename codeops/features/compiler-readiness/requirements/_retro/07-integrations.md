# Integrations: Blend65 Compiler Readiness

> Generated by retro-requirements — Phase 7: Integrations · Date: 2026-07-23

## Integration Map

| System | Direction | Purpose | Failure class |
|---|---|---|---|
| Local filesystem | read/write | Sources, configuration, assembly and binaries | I/O/path diagnostic |
| ACME | outbound process | Assemble emitted 6502 source | assembler failure |
| VICE 3.10 | outbound process | Execute C64 binaries and expose observations | timeout/runtime mismatch |
| Node/Yarn/Turbo | build environment | Build and test the compiler | infrastructure failure |
| Language Server Protocol | bidirectional editor protocol | Diagnostics and language tooling | tooling disagreement |
| GitHub Actions | CI executor | Repeat non-emulator verification | environment/coverage gap |

## Boundary Requirements

- Generator failures, compiler failures, assembler failures, emulator timeouts and semantic
  mismatches must remain distinguishable.
- A missing optional emulator must skip only the declared runtime tier, never convert it to a pass.
- Temporary files and subprocess arguments must be deterministic and safely constructed.
- CI must run all non-emulator generator tiers; a scheduled or required environment must run the
  emulator tier before a readiness release.
