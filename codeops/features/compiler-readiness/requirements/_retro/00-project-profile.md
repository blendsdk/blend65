# Project Profile: Blend65 Compiler Readiness

> Generated by retro-requirements — Phase 0: Reconnaissance
> Date: 2026-07-23 · Source: repository root

## Identity

- **Name:** Blend65
- **Type:** statically typed systems language, AOT compiler, CLI and editor tooling
- **Version:** 0.1.0
- **Purpose:** let modern programmers produce expert-quality 6502 programs for C64 and related
  platforms without requiring assembly-language workarounds.
- **Reconstruction boundary:** readiness of the compiler against the frozen Blend65 v3.0 language
  specification. Performance parity is downstream evidence, not the readiness definition.

## Technology Stack

| Layer | Technology | Evidence |
|---|---|---|
| Language | strict TypeScript ESM | `tsconfig.json`, package sources |
| Workspace | Yarn classic, Turborepo | `package.json`, `turbo.json`, lockfile |
| Compiler tools | ACME assembler | test harness and compiler assembly path |
| Runtime validation | VICE 3.10 locally | emulator-backed acceptance suites |
| Tests | Vitest | 244 specification tests and 130 implementation tests by file count |

## Scale Estimate

- Ten workspace packages.
- 607 TypeScript source and test files under `packages/`.
- 50 Markdown language-specification documents.
- Compiler pipeline, CLI, language server, VS Code extension and test harness in one monorepo.
