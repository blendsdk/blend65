# Architecture Analysis: Blend65 Compiler Readiness

> Generated by retro-requirements — Phase 1: Structural Analysis · Date: 2026-07-23

## Architecture Style

Layered compiler monorepo with explicit package boundaries and a staged pipeline.

## Layer Map

| Layer | Directory | Requirement-level responsibility |
|---|---|---|
| Language contract | `spec/` | Defines accepted programs, semantics and diagnostics |
| Shared model | `packages/core/` | Carries syntax, types, diagnostics and target facts |
| Frontend | `packages/frontend/` | Accepts/rejects programs and constructs the semantic model |
| Allocation | frontend SFA | Assigns compile-time storage without changing semantics |
| Lowering | `packages/codegen/src/il/` | Converts valid programs into target-independent operations |
| Target codegen | `packages/codegen/src/instr/` | Selects 6502 instructions and layouts |
| Orchestration | `packages/compiler/` | Exposes compile/emit/build operations |
| User surfaces | `packages/cli/`, language tooling | Presents compilation and diagnostics |
| Validation | `packages/test-harness/`, tests | Assembles and executes outputs; records observations |

## Entry Points

| Entry point | Purpose |
|---|---|
| Compiler public API | Analyze, emit assembly and build target artifacts |
| `blendc` CLI | User-facing build/check operations and reports |
| Language server | Editor diagnostics and language intelligence |
| Test harness | Compile, assemble and run controlled programs |

## Dependency Direction

```text
spec (normative, no runtime imports)
  ↓ interpreted by
core ← frontend ← codegen
  ↑        ↑          ↑
config/platforms      compiler ← cli
             test-harness ───────┘
core ← frontend ← language-server ← vscode
```

The language server is intentionally prohibited from importing codegen. This keeps semantic
diagnostics independent from target emission.

## Architecture Decisions Observed

| Decision | Observed choice | Readiness significance |
|---|---|---|
| Specification baseline | `spec/` frozen during implementation | Prevents fixing code by silently changing the contract |
| Static allocation | Frame and storage decisions occur before runtime | Generated programs require no general allocator |
| Diagnostic recovery | Invalid constructs produce structured diagnostics where handled | Enables generated negative testing |
| Assembly boundary | ACME consumes emitted text | Assembler legality is a distinct verification gate |
| Emulator boundary | VICE observes C64 runtime state | Provides an execution oracle independent of assembly text |
| Peephole stage | Present but currently empty | Readiness must not depend on optimizer maturity |
