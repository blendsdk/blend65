## Current program boundary

The v4 correctness track and the optimizer track are separate. The default `none`
compiler is the release baseline. RD-08's saved/acquisition gates pass with the
unchanged 963/725 limits; all four modes are wired, and balanced/speed publish
the validated size-quality output. RD-01 through RD-10 are done. RD-06 closed at
151/151 and RD-07 closed at 131/131: loadable units, a deterministic D64 serializer,
the KERNAL loader, destination constraints and per-candidate failure precision, exact
field memory states, evidence and bounded VICE runtime proof are delivered. The final
release boundary reports compiler 218 files / 3,683 passed / 2 skipped, CLI 73,
language server 21, VS Code 18, and root 6,570 passed / 4 skipped plus one corrected
docs oracle. RD-06 and RD-08 residual output debt remains tracked in open issues. Issue
#150 closed the NMI Boolean/residual line: the wide word-mask join, computed runtime
mask, nonzero byte and word comparisons, capacity-bounded retention, and
multi-block/calling retention are delivered, and the `v4-nmi-retained-source-reads`
ledger row is retired. The none-mode ordinal-write gap, the multi-screen
`setSpritePointer` restriction and the frozen compile-time `const` VIC field remain
tracked debt. The GoatTracker 2.77
adapter remains a separate follow-up feature. RD-09 closed with the shared tooling
index, production language server, canonical formatter, CLI JSON/evidence adapter,
thin VS Code client, and completed debug load identity. RD-10 approved the bounded
production transition on `linux/x64` for four KERNAL PRG profiles plus one D64. The
post-approval `V4-TAKEOVER-1` update delivers the four raw-takeover PRG profiles with
sequential VICE startup/return proof; source-installed raw NMI (`V4-TAKEOVER-F2`) and
raw-MMIO interrupt containment (`V4-TAKEOVER-F3`) remain bounded follow-ups. T-30 closed the two
remaining v4 expressiveness defects: T-15 legal partial fixed-array construction and T-10 helper
callable assignment. The helper transfer is bounded to a bare callable global with no placement or
taken address and direct-source stores; raw-memory corruption remains the accepted AR-P1 risk owned
by #156, and aggregate-field transfer remains #157 precision debt. Physical (`V4-HW-1`), native
Windows/macOS (`V4-HOST-1`), and producer/adapter (`V4-ASSET-1`)
debt keep named owners. No physical C64 is available, so physical claims stay
`VICE-verified / hardware-unverified`.
The remaining open rows are sequenced as one serial worklist in
[session worklist](plans/issue-wave-delivery/99-execution-plan.md#session-worklist--run-top-to-bottom-2026-11-21):
that document holds the order and nothing else, while these rows hold the state and nothing
else, so the two cannot disagree.
No oracle, source contract, behavior assertion or limit is waived or deleted.
