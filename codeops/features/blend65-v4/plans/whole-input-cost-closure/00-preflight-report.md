### PF-001: precise lives omit actual access occupancy — 🟠 MAJOR

**Dimensions:** 2 Implicit Assumptions; 13 Codebase Alignment.
**Reviewer identity:** storage cluster SF-001.
**Target location:** `03-01-source-facts.md:59`, particularly lines 59–68;
`03-02-machine-selection.md:50`; `07-testing-strategy.md:45`.

The proposed use/kill liveness does not explicitly require a surviving dead
definition to occupy its home at the write point. Nor does it extend a backing
home when a semantic load becomes a deferred physical read. The interference
consumer checks only intersections of `liveAt`.

Actual evidence: `storage/interference.ts:45` intersects positions;
`machine/lower-operation.ts:237` still emits ordinary whole-binding stores;
its line 219 can retain a storage-backed loaded value until a later consumer.
`machine/lower-call.ts:110` marshals every parameter before JSR;
`machine/lower-aggregate.ts:273` emits member writes. Paths are relative to
`packages/compiler/src/`.

Minimal future probe: `a=0; poke(C101,a); b=7; a=9; poke(C100,b)` using two
local bytes. The last assignment to `a` has no future value use but still writes.
If `a` and live `b` share a home, the last observable result changes from 7 to 9.
There is no escape, unknown address or interrupt uncertainty in this example.

**Refutation attempted:** matching selected recipes and final observer validation
do not themselves supply read/write conflicts. Existing whole-function lives
remain conservative and safe. This is a missing planned proof, not evidence of
a current baseline miscompile.

**Surviving remediation:** map every selected surviving definition/member/marshal
write to occupancy conflicts, and retain backing homes through deferred reads.
Keep conservative lives where that map is unproved. Add the dead-write, member,
marshal and deferred-read counterexamples to ST-16. No general dead-store pass
or new machinery is required. Permanently retaining all conservative lives would
avoid corruption but would not provide the approved precise-overlay consumer.

**Recommendation — Best option:** close every selected surviving access's physical
occupancy, with conservative fallback and the four ST-16 counterexample groups.
This is a direct correction within AR-P4's approved lifetime/interference family.
**Confidence:** High; emitter removal/materialization evidence could change it.
**Hardening:** challenger converged; DSE was rejected as unnecessary.
**Strongest counterargument:** selected-access mapping adds work, but fallback
keeps that work incremental without risking corruption.
**User Decision:** Resolved — user accepted the recommendation on 2026-10-12,
with the explicit anti-overengineering condition quoted above. Document fix
