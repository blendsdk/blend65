# Requirements: Canonical fixed-object ABI

> **CodeOps Artifact Schema**: 1
> **Scope authority**: AR-P6; root task1.1.6

| ID | Requirement |
| --- | --- |
| C-1 | Canonical `none` may replace a proved returned local's hidden result pointer with its unique authenticated caller-owned backing. Require complete calls, freshness, early-publication safety and exact source identities. |
| C-2 | Borrowed aggregate parameters may use that same backing only when their complete call set proves that exact object. No program-wide aggregate-return switch or unrelated borrower specialization. |
| C-3 | Missing/ambiguous eligibility or unclosed physical obligations retain the legal generic ABI. Malformed internal provenance remains an invariant failure, never permission to publish unsafe output. |
| C-4 | Preserve values/order, volatile identity/count/order, aggregate snapshot/alias semantics, nested calls, initializers, interrupts and ordinary calling behavior. No source restriction. |
| C-5 | SFA closes actual parameter/result/local/temporary/helper demand before emission. Removed pointers have no surviving access; fixed backing remains declared, live and interference-safe. No late storage invention. |
| C-6 | Preserve Direct/Original operation selection, startup choice, generic fallback, unrelated borrowers and optimized recipes. Object facts cannot activate byte/complement/loop optimization. |
| C-7 | Public API/schema/options/diagnostics, all old tests/fixtures, profile/ZP windows, resource ceilings and pinned artifacts stay fixed. |
| C-8 | All unchanged ordinary/acquisition four-profile gates pass with real caller preservation. BASIC saves disappear only when the actual borrowed addresses disappear. |
| C-9 | Independent behavior and assembly/resource expectations pass. Complete root `yarn test` exits zero before RD-05 qualification resumes. |
| C-10 | Authentic observer metadata is available for both final constructions without enabling stronger bounds, folding, data removal or changed generic demand/startup. Optimized construction remains unchanged. |
| C-11 | Byte-loop and conditional MMIO admission requires actual unchanged-control correspondence in both layouts, limited to independently certified ABI substitutions/relocation. Preserve raw order/count, pointer/dummy accesses and physical envelopes; invent no induction facts. |

No specification/expert/requirement-set edit, game policy, runtime, optimizer
frontier, general ABI engine or dependency is authorized. Word-counter root
work remains with its separate existing owner.
