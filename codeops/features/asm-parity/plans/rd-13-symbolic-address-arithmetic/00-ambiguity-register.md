# Ambiguity Register: RD-13 Symbolic Address Arithmetic (plan stage)

> **Status**: ✅ GATE PASSED — all 9 items resolved (88–96), 2026-07-21
> **Scope**: plan-stage decisions for
> [RD-13](../../requirements/RD-13-symbolic-address-arithmetic.md)
> ([#58](https://github.com/blendsdk/blend65/issues/58) — the symbolic-address slice)
> **CodeOps Skills Version**: 3.11.0

Numbering continues the feature-wide sequence (RD-stage items 78–82 and preflight runtime items
83–87 live in [`requirements/00-ambiguity-register.md`](../../requirements/00-ambiguity-register.md))
so a single `AR #n` is unambiguous across asm-parity.

**Imported pre-resolved** from the RD stage and its preflight, not re-litigated here: the M1/M2/M3
scope split; the exclusion of `hi(&X) * 4` from the fold; the exclusion of `const` declarations
naming link-time addresses (spec-blocked under D3); `hi(&X / 2^k)` and the word-context forms
keeping their current paths; the deliberate absence of an offset field on the new instruction
operand; the re-routing of 16 divergence rows to
[#70](https://github.com/blendsdk/blend65/issues/70); and `W10172` being left producer-less with
[#71](https://github.com/blendsdk/blend65/issues/71) as its owner.

| 88 | Architecture | How a byte-selected (and optionally shifted) link-time address is represented in `ILOperand` and `InstrOperand`. | 89 | Behavioral | Which shift counts the M2 fold accepts, and the behaviour at both ends of the range | (a) `k = 1..15`; `k = 0` (`/1`, `>>0`) degenerates to M1's plain byte-select; `k >= 16` falls through to the current unchanged path with no new diagnostic / (b) `k = 1..7` only | ✅ Resolved — User accepted recommendation: **(a)**. `lo()` truncates by definition, so every `k` is already in immediate range and a cutoff at 7 would be arbitrary. `k = 0` degenerating avoids emitting `#<(sym / 1)`, which assembles to the same byte but reads as noise in the listing. `k >= 16` and non-power-of-two divisors keep today's behaviour — this RD adds no diagnostics | ✅ Resolved |

Phase 4 grows by 2 tasks (50 → 52) | ✅ Resolved |
