# Compiler-readiness artifacts

The JSON inventory under `inventory/` is authoritative. The identity ledger is append-only, and
the review file records independent semantic approval against reproducible inventory digests.
Files under `generated/` and the declaration module in
`packages/readiness/src/generated/` are derived projections.

From the repository root:

- `yarn readiness:check` validates that both committed projections match the current inventory
  without writing any file.
- `yarn readiness:generate` explicitly regenerates both projections while holding the
  PID/token-owned publication lock.

Generation renders both outputs from one inventory read before publishing them. Each output embeds
the same generation digest, allowing check mode to detect a stale or mixed pair after an interrupted
publication. Authoritative inventory, identity, and review-evidence files are never generated by
these commands.
